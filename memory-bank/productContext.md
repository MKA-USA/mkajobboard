# Product Context: SoT Job Board

## Purpose
To create a centralized platform for School of Technology students to find relevant job opportunities and for employers to connect with qualified candidates.

## Problem Statement
Students need an efficient way to find technology-focused job opportunities, while employers need a direct channel to reach qualified tech students.

## User Personas

### Students
- Tech students seeking internships/jobs
- Need easy access to relevant opportunities
- Want to showcase their skills
- Need to track applications

### Employers
- Companies seeking tech talent
- Want to reach qualified candidates
- Need to manage job postings
- Want to track applicant progress

### Administrators
- School staff managing the platform
- Need to oversee job postings
- Want to ensure quality control
- Need to manage user access

## Key Value Propositions
1. Centralized job search for tech students
2. Direct access to tech talent for employers
3. Quality control through school oversight
4. Streamlined application process
5. Skills-focused matching
