# Project Brief: SoT Job Board

## Overview
A job board application for the School of Technology to connect students with potential employers.

## Core Requirements
- Job posting and management
- User authentication and profiles
- Search and filter functionality
- Responsive design
- Accessibility compliance

## Technical Stack
- React + TypeScript
- Tailwind CSS
- Vite
- Supabase

## Key Features
- Job posting system
- User authentication
- Profile management
- Search functionality
- Responsive UI
- Admin dashboard

## Success Criteria
- Intuitive user interface
- Fast performance
- Mobile responsiveness
- Accessible to all users
- Secure data handling
